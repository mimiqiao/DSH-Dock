# Original desktop artwork

All current SVGs in this directory are original vector artwork created for DSH Dock on 2026-11-10 and distributed under the project MIT license. The wallpaper uses original abstract curves; icons use ordinary folder, document, grid, gear, media and clock motifs. No Apple wallpaper, application icon, logo or traced system artwork is included in the current release. The macOS-style window and Dock layout is retained.

Earlier private development revisions used local system images. Those historical third-party images are not covered by the project license and are not part of current distribution artifacts.
