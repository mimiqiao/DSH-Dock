## 真实 Harness 隔离集成

使用已安装 DeepSeek Harness 的 web profile，独立 `DSH_HOME=/tmp/desk-harness-integration`、端口 43190；没有重启正在运行的用户 Harness。测试源文件和派生文件都在隔离目录。没有使用用户模型密钥，没有调用付费模型。

执行环境注入本地确定性 QA 模型：它通过真正的 LlmAdapter 接收请求、读取附件完整字节，输出本地 HTML 派生文件。宿主的认证、会话创建、工作区、通用上传、receipt 接收、prompt、持久会话日志、投影均为真实实现。来源索引为测试生成。这个测试证明宿主集成，不衡量真实 DeepSeek 的创作质量，也不代表逐一验证了 Office 文档解析能力。

- HTML 演示稿、PNG、Markdown 文档分别完成完整文件上传 → 新会话任务 → 派生文件 → 成果工作台重新收集。三个原件的 SHA256 在操作前后相同。当前实现统一使用通用文件通道，图片保留原始字节。
- 重启隔离 Host，重要标记与已提交复用记录保留。
- 显式保存文档版本后暂时移走原件，仍能查看完整内容并以正确 `.md` 文件名下载；测试结束恢复原件。
- 拦截已提交任务的插件确认写入并返回 503，再点击开始：复用记录一条、相同 requestId 对应的真实 user/message 一条，文件附件一份。宿主在消费 receipt 前检查已有 requestId。
- 未认证浏览器读取成果库返回 401；已认证连接正常读写。Host exact fetch route 的 owner 检查来自当前安装版本的宿主实现。

## 交付边界

- 版本只保存用户明确选择的内容，不自动推断历史文件。只有当前路径时明确提示读取当前文件；只有讨论时明确保存摘要；只有保存预览时不冒充原图。
- 每份版本上限 50 MiB，HTML 不自动打包所有外部/相对资源。PPTX 仍是简版文字图片预览，其他格式按浏览器支持预览或下载。
- 复用创建新任务并附来源文件，插件不覆盖原稿；Agent 的后续写入仍依赖 Harness 的工具权限。复用计数表示任务已提交，不表示生成质量或用户验收。
- 首版按月回顾、单个浏览窗口；macOS 风格在插件面板内，不接管系统桌面。重要标记与偏好是当前 Harness 数据目录内的个人整理。
- 此次未在用户真实模型上运行付费生成，也没有提交、推送或发布。当前安装以符号链接使用该目录；用户退出并重新打开 Harness 后加载新版 Host 投影与客户端。
