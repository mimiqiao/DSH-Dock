# macOS 桌面重做验证

日期：2026-11-10。

## 改动

- 删除“对话中的工作会自动整理到这里”。
- 以 macOS Sonoma 桌面为视觉基准：从本机提取真实壁纸及 Finder、设置、预览、文本、音乐、视频、终端等系统图标，构建为内嵌图片，无运行时网络/系统目录依赖。素材来源保留在 assets/macos/README.md。
- 重做 28px 菜单栏、右侧文件网格、原生文件图标与选中态、磨砂 Dock、悬停效果、运行指示点、分隔线。
- 设置位于 Dock，可在 Finder 窗口打开时使用，菜单向上展开；风格切换保留当前打开内容。桌面没有重复悬浮设置。
- Finder 增加真实可操作分类侧栏、灰白窗口材质、红黄绿按钮、标题与返回控件。macOS 窗口为非模态，Dock 及桌面可交互；物件桌面继续保持模态焦点约束。
- 窄屏修正标题栏按钮遮挡；成果详情收起侧栏，保留可用阅读宽度。
